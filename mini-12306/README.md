# Mini-12306 Web 端铁路票务系统

基于 Python Flask 实现的简化版 12306 在线票务系统，满足课程/教学实践需求。

## 功能特性

- **用户端**：实名注册、登录、车次查询、余票查看、在线购票、模拟支付、退票、改签、订单管理、消息通知
- **管理端**：用户管理、车站管理、车次管理、排班管理、订单管理、审计日志
- **第三方服务模拟**：实名认证、在线支付、短信通知（控制台输出）

## 技术栈

- Python 3.10+
- Flask + Flask-SQLAlchemy
- SQLite 数据库
- Bootstrap 5 前端

## 快速开始

```bash
cd mini-12306
pip install -r requirements.txt
python app.py
```

浏览器访问：http://127.0.0.1:5000

## 业务流程

1. **注册**：填写实名信息 → 身份证认证 → 创建账号
2. **购票**：查询车次 → 选席别/乘车人 → 创建订单 → 支付 → 出票
3. **退票**：校验规则 → 计算手续费(5%) → 退款 → 释放余票
4. **改签**：选择新车次 → 计算差价 → 补/退差价 → 更新车票
